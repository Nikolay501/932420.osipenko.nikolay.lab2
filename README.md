# Лабораторная работа №2. Базовые и продвинутые возможности CSS

Это моя вторая лабораторная работа. Здесь я красиво оформил страницу из первой лабрраторной с помощью CSS. 

## Что реализовано (по заданию):

* **3 способа стилизации:** основной код вынес в файл `style.css`, добавил тег `<style>` в HTML и один встроенный стиль (атрибут `style`).
* **Переменные:** все основные цвета и шрифты записал в `:root`.
* **Позиционирование:** использовал `relative` и `absolute`, чтобы сделать плашку «Астроном» поверх фотографии, а также `static` для основного блока.
* **Псевдоклассы:** добавил эффекты для ссылок, полей ввода и кнопок (`:hover`, `:active`, `:focus`, `:visited`).
* **Контрастность:** подобрал темный фон и светлый текст, чтобы всё хорошо читалось.
